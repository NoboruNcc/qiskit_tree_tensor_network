# Qiskit Tree Tensor Network

## プロジェクト概要
このリポジトリでは，IBMのオープンソース量子コンピューティングフレームワークであるQiskitを使用して，ツリーテンソルネットワーク（TTN）[1]を実装した．
qiskitとqiskit_machine_learningの学習目的のために実装した．
実装の際には，[2]を参考にした．

## インストール
poetryを使用．
pythonのバージョンは3.10以上を推奨．
```bash
poetry install
```

## 参考文献
[1] Grant, E., Benedetti, M., Cao, S. et al. Hierarchical quantum classifiers. npj Quantum Inf 4, 65 (2018). https://doi.org/10.1038/s41534-018-0116-9

[2] https://zenn.dev/derwind/articles/dwd-qiskit15
